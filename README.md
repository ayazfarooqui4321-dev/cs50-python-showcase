# CS50 Python Showcase

A curated set of CS50 Python exercises and mini-apps demonstrating clean code, problem solving, and CLI UX.

## Contents
- **grocery/** – Grocery list CLI (parsing, input validation, counters).
- **bank/** – String parsing & conditional logic.
- **camel/** – snake_case ⇄ camelCase conversion.
- **plates/** – Validation kata (custom rules).
- **fuel/** – Fractions → percentages with error handling.
- **twttr/** – Text filters & string ops.
- **faces/**, **indoor/**, **playback/** – Small text/IO utilities.
- **taqueria/**, **tip/**, **meal/**, **nutrition/** – Small calculators/parsers.
- **einstein/**, **deep/**, **outdated/**, **coke/** – Mini scripts & warm-ups.
- **interpreter/** – Simple expression interpreter.
- **extensions/** – File-extension detection.

> Each folder is self-contained; open it to see the script(s) and any README/tests inside.
